# Roadmap web

## Fase 1

- portada corporativa terminada
- contacto por email operativo
- pagina de noticias preparada

## Fase 2

- definir mensajes comerciales definitivos
- publicar primeras noticias reales
- preparar pagina de servicios o modulos
- revisar SEO basico y metadatos compartibles

## Fase 3

- incluir casos de uso o ambitos de aplicacion
- incorporar documentacion descargable o fichas
- estudiar CMS ligero o generacion estatica si aumenta el contenido

## Fase 4

- valorar framework de contenido si hay blog, recursos o multiples secciones
- preparar integracion con formularios o CRM si deja de bastar el email
