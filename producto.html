Producto QontrolMed

Una suite para coordinar sobremesa, trabajo de campo e informes tecnicos en entornos sanitarios.

QontrolMed integra una aplicacion matriz en Windows y dos aplicaciones offline de campo para tablet. El resultado es una operativa mas ordenada para preventivos, revisiones IT en quirofanos y seguimiento documental con base tecnica.

Suite

Una estructura modular para cubrir la operativa real.

La propuesta de valor de QontrolMed no depende de una sola pantalla. Se basa en una suite coordinada que reparte bien el trabajo entre configuracion de sobremesa, captura en campo y cierre documental.

Aplicacion matriz

Sobremesa para gestion, maestros y gobierno del dato

La aplicacion principal organiza modulos de gestion, quirofanos y preventivos sobre una base comun de permisos, usuarios, catalogos y operaciones.

  • Gestion de centros, equipos, compras y configuracion.
  • Acceso por permisos a informes, libro y operaciones de importacion o exportacion.
  • Preparada para trabajo tecnico, revision final e impresion documental.

Preventivos en tablet

Captura offline con SQLite y vuelta controlada a sobremesa

La app de preventivos para tablet importa maestros desde la matriz, permite crear o retomar informes, cerrarlos y exportar resultados a JSON para su descarga posterior.

  • Importacion de tipos de equipo, plantillas, equipos, puntos y usuarios.
  • Conservacion de contexto de campana mediante `id_campana` cuando aplica.
  • Recuperacion de informes cerrados si se necesita revision o reapertura.

Revisiones IT en quirofano

Ciclo mensual de campo alineado con el modelo de la matriz

La app movil de quirofanos trabaja con el mismo contrato de datos que la aplicacion principal para registrar cabecera, resultados por punto, observaciones y exportacion final del ciclo.

  • Modelo alineado con hospitales, quirofanos, puntos y equipos de medida.
  • Uso en Windows y distribucion Android mediante APK para pruebas de campo.
  • Capacidad de reabrir y revisar informes cerrados dentro del propio flujo.

Flujo operativo

Del dato maestro al informe final sin improvisar el recorrido.

El valor comercial de QontrolMed esta en combinar practicidad de campo y control tecnico. El trabajo no se deja en una exportacion suelta: se apoya en contratos, validaciones y estados de informe pensados para no perder contexto.

01

Preparacion desde matriz

Se organizan maestros, plantillas, puntos de control y permisos antes de enviar un paquete a campo.

02

Importacion validada

La tablet valida estructura y referencias antes de tocar SQLite para evitar mezclas o corrupciones silenciosas.

03

Captura y cierre en campo

El tecnico guarda avances, completa puntos, registra observaciones y cierra cuando el trabajo queda terminado.

04

Exportacion de resultados

Los informes cerrados se devuelven a sobremesa mediante JSON, manteniendo contexto funcional y trazabilidad.

05

Revision y salida documental

La matriz queda preparada para completar datos finales, imprimir informes y consolidar historico operativo.

Contratos de datos controlados

Trazabilidad de informes

Estados de trabajo, cierres, reaperturas y contexto de campana quedan reflejados en el propio flujo.

Modelo alineado con la matriz

La capa movil reutiliza nombres de tablas y conceptos de negocio para no duplicar complejidad innecesaria.

Orientacion a entorno sanitario

Quirofanos, instalaciones IT, preventivos y equipos tecnicos forman parte del lenguaje natural del producto.

Base preparada para crecer

La arquitectura actual deja hueco a nuevas capas de analitica, servicios, casos de uso y material comercial.

Resultado documental

Informes legibles para revision tecnica y entrega profesional.

QontrolMed no termina en la captura. La salida debe ser util para ingenieria, mantenimiento, auditoria interna y cliente final. Por eso la capa documental tiene peso propio en la web y merece mostrarse con capturas limpias.

  • Cabeceras claras con identificacion de sala, periodo y equipo.
  • Bloques de medidas, estados y observaciones faciles de revisar.
  • Base adecuada para futuras variaciones por cliente o por tipo de informe.
